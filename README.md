# vocal-text-bridge

> Vocal text bridging web application.

## 📖 Overview
A frontend React/Vite application utilizing shadcn UI for modern component design.

## 🛠️ Built With
* **Framework:** React `18.3.1` (TypeScript)
* **Build Tool:** Vite `5.4.1`

## 🚀 Getting Started

### Prerequisites
* Node.js (v18 or higher)
* npm or yarn

### Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/mohitshukla02/vocal-text-bridge.git
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```
